# Third-party notices and bundled asset provenance

## Current binary asset inventory

The authoritative, machine-checked inventory is
[`docs/bundled-assets.json`](docs/bundled-assets.json). It currently contains no
entries: this repository and its deployed application do not bundle image,
font, audio, video, archive, PDF, or WebAssembly binaries. Visual decoration is
implemented in project-authored CSS and JSX/SVG source.

`scripts/asset-provenance.node-test.mjs` compares every tracked file with a
binary-asset extension against the manifest. A future binary cannot pass the
repository validation unless its source, author, license, permission status,
and evidence are recorded, and redistribution permission is marked verified.
