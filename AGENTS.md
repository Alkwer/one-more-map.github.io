# Repository GitHub policy

- Treat `https://github.com/Alkwer/one-more-map.github.io` (`origin`) as the
  canonical repository for pull requests and merges.
- Never create a pull request against
  `https://github.com/one-more-map/one-more-map.github.io` (`upstream`) unless
  the user explicitly requests an upstream pull request.
- Unless the user names another branch in `origin`, target pull requests at
  `Alkwer/one-more-map.github.io:main`.
